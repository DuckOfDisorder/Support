## Code for my support site, using PayPal's "checkout button".
---
If you are here because you want to code your own quick support site, I would suggest avoiding PayPal! Paypal subtly adds a currency coversion fee, and has horrible transaction fees in general. 

Other payment processors offer their own "quick checkout" buttons! Be sure to look at your options! Unfortunately, a lot of them are unavailable to me, so I have to stick with PayPal, and I hope you get through whatever you need this site for.
